[B]1.0.42[/B] (2025-10-27)
- Changed: Simplified scheduling - removed time-based syncs (interval/fixed time)
- Changed: Schedule modes now: "On startup only", "On shutdown only", "On startup and shutdown"
- Removed: Interval minutes and fixed time settings (not practical when Kodi isn't always running)
- Removed: Separate "Run on startup/shutdown" checkboxes (now part of schedule mode)
- Simplified: "Enable automatic sync" checkbox with single mode dropdown
- Improved: Cleaner, more logical scheduling interface

v1.0.41 (2025.10.26)
- Added: HTTP(S) backend driver (GET/PUT with auth header support)
- Added: SMB/NAS backend driver (UNC paths: \\server\share\path)
- Added: NFS backend driver (mounted NFS paths)
- Added: S3 backend driver (AWS/MinIO/Wasabi - requires boto3 library)
- Added: SFTP backend driver (requires paramiko library)
- Changed: All 7 backend types now implemented
- Note: S3 and SFTP require additional Python libraries
