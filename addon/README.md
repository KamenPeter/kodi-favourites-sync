# Kodi Favourites Sync (Cloud)

Addon ID: `plugin.service.favourites-sync`  
Version: 1.0.0

This is a skeleton ready for development by an AI assistant or developer.
See README for structure; install with **Install from ZIP** using the packaged archive in this folder.

## Quick Dev Notes
- Program entry: `resources/lib/addon.py`
- Service entry: `resources/lib/service.py`
- Configure Cloud Location in Settings and hit **Validate endpoint**.
- Strings localized in `resources/language/*/strings.po`.
